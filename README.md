# 黔行 · 贵州景区导览

一个不依赖构建工具和前端的纯静态前端项目，用于按等级展示贵州旅游景区，并提供注册、登录、景区收藏与评分评价功能。

## 功能

- **按等级浏览景区**：按 5A、4A、3A 分组展示，每个景区包含名称、所在地、简介、评分、标签、最佳季节、参考票价等信息。
- **搜索与筛选**：支持按景区名称、城市、简介、标签搜索，并可单独筛选某一等级。
- **景区详情页**：点击卡片跳转到独立页面 `spot.html?id=<景区ID>`，查看完整介绍、不可错过的亮点、建议时长和地址；页面横幅使用该景区的实景照片。
- **注册 / 登录**：账号保存在浏览器 `localStorage`，登录状态跨页面共享。
- **收藏景区**：登录后可收藏 / 取消收藏，未登录时点击收藏会提示先登录。
- **评分与评价**：登录后可在景区详情里打 1–5 星并写下最多 200 字的评价，同一账号对同一景区可修改或删除；未登录只能查看。卡片与详情的评分会按“景区基础评分 + 本机账号评价”实时汇总。
- **我的收藏**：收藏列表按最近收藏排序，支持取消收藏与查看详情。
- **全屏轮播首屏**：首页顶部为铺满整个视口的轮播（黄果树瀑布、梵净山、遵义会议会址、赤水丹霞、小七孔、织金洞，加上品牌页共 7 屏），每 3 秒自动切换，支持左右箭头手动切换；导航悬浮在图片上，页面滚动后自动转为实色底。
- **响应式布局**：适配桌面、平板与手机。

## 运行方式

项目没有 Node.js 依赖，直接用浏览器打开 `index.html` 即可；推荐通过本地 HTTP 服务访问，以保证 `localStorage` 和密码哈希行为一致：

```bash
# 在项目根目录执行
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

Windows PowerShell 也可以使用：

```powershell
python -m http.server 8000
```

## 数据与账号说明

- 演示数据共 20 个景区（5A 8 个、4A 8 个、3A 4 个），景区等级与票价仅用于界面演示，请以贵州省文化和旅游部门的最新公告为准。
- 账号、登录状态、收藏与评价均保存在当前浏览器的 `localStorage` 中，不会上传到服务器；清除站点数据会同时清除这些记录。存储键为 `qianxing_users_v1`、`qianxing_session_v1`、`qianxing_favorites_v1_<用户名>`、`qianxing_reviews_v1`。
- 评价规则：一个账号在一个景区最多保留一条评价，可随时修改或删除；星级为 1–5 整数，文字最多 200 字。展示评分 = 景区基础评分与本机评价的加权平均。
- 详情页每个景区另有 2 条内置「示例评价」（共 40 条），由项目作者依据景区公开资料撰写，仅用于演示评价区排版与交互；它们不是从高德地图等平台抓取的真实用户评论，也不计入评分，界面上以「示例」标签标注且只读。
- 景区评分为演示基准分。如需换成真实评分，可接入高德开放平台「地点搜索」接口返回的 `biz_ext.rating` 字段：需自行申请 Web 服务 Key，并建议通过后端代理调用，避免 Key 直接暴露在前端。
- 密码优先使用 Web Crypto 的 SHA-256 做摘要存储；浏览器不支持时降级为本地演示哈希。该项目仅用于前端演示，不是生产级认证方案。

## 后续接入后端

若要将收藏、评价与账号迁移到真实服务端，只需替换 `assets/js/store.js` 中的 `register`、`login`、`logout`、`getFavorites`、`toggleFavorite`、`getReviews`、`saveReview`、`deleteReview` 等方法，保持返回值和 `qz:authchange`、`qz:favchange`、`qz:reviewchange` 事件不变，页面层无需修改。
